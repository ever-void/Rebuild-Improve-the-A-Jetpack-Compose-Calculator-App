# Rebuild-Improve-the-A-Jetpack-Compose-Calculator-App

I wrote the code for the app and then committed it to git, so there aren't many updates unfortunately.

Overview:
This app acts as a calculator and can add, subtract, divide, multiply, change a number's sign, and take percentages.
It can alco clear, calculate, delete numbers.
I made the app following the provided instructions and I chose to add sign changing (+/-) and percentages (%) as my enhancements.

To set up and run the app from the repository, the repo needs to be cloned in android studio using git clone https://github.com/ever-void/Rebuild-Improve-the-A-Jetpack-Compose-Calculator-App.git
Once the cloning is done, you can open the project in studio and let the gradle sync.
Once it syncs, you should be able to run the calculator.

List of enhancements:
- Percentages
- Change signs

Reflection:
I found the project challenging, but also interesting. I wasn't expecting something made only with code
to look nice, but I think it looks good. I could have taken more care o have the +/- button be in a different
place or have a different color, but my main focus was to make sure it worked before the deadline.
Overall, I'd say I'm happy with the results of the project, especially considering I did it all in one day due to
having a very busy schedule since I'm taking 21 credit hours and working part time.

Notes:
Since I only added two enhancements, I didn't need to worry too much about button space and placement. All I needed to do was
make the 2-wide buttons 1-wide and add two others in that space. If I had been adding more, I would have found it challenging
do arrange all the buttons in a way where their size was not too small but also that their arrangement wasn't weird or bad looking.
It is something I will consider in the future when working on my final project.
